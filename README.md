# Projet Galactica

#Ce projet permet à l'utilisateur de gérer une flotte de vaisseaux spatials ainsi que de pouvoir personnaliser leurs équipages à travers un menu totalement interactifs et fonctionnels et des évenements aléatoires.

#Fonctionnalités
-Renommer la flotte pour une personnalisation
-Ajouter un membre d'équipage
-Supprimer un membre d'équipage
-Ajouter un vaisseau
-Supprimer un vaisseau
-Vérifier la préparation du vaisseau
-Afficher les statistiques de la flotte
-Sauvegader et charger les données de la ou les flottes créer auparavant

#Fichiers
main.py : Contient le code principal et le corps du programme
fleet.py : Contient la classe fleet pour la gestion de la flotte
spaceship.py : Contient la classe spaceship pour la gestion des vaisseaux
crew.py : Contient les classe member operator et mentalist qui servent à la gestion des membres et des rôles de l'équipage
fleet.json Fichier de sauvegarde en json pour charger les flottes

#Instructions
Exécutez le fichier main.py pour démarrer le programme
Suivez les instructions du menu interactif
